# AI Context - GO2 GUI & Visualization Sub-repository

## Feladatkör
Ez az alrepó a felhasználói felületeket, webes dashboardokat és 3D vizualizációs nézeteket tartalmazza:
- `web_dashboard/`: Three.js alapú 3D Digital Twin, HUD és joystick vezérlő.
- `mock_robot/`: UI fejlesztői szimulációs szerver.
- `go2-console/`: Integrált szerver és webes vezérlőkonzol.
- `html_workbench/`: Önálló SLAM és 3D elemző HTML munkaterületek (`slam_workbench.html`, `compare_3d.html`, stb.).

## Hálózati & Kommunikációs Interfészek
- ROSBridge / WebSockets: `ws://localhost:9090`
- WebRTC Video Stream: `http://localhost:8080/stream`
- Control Commands: WebSocket JSON üzenetek (`{ "action": "move", "vx": 0.5, "vy": 0.0, "vyaw": 0.0 }`)

## Önálló GUI Fejlesztés & Tesztelés
UI módosításakor a szerver és a kamu robotadatok elindítása:
```bash
python mock_gui_data.py
```
